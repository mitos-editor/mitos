# Package managers

Mitos is not yet published through third-party package managers. Use the
[hosted installers or release archives](./install.md), or
[build from source](./building-from-source.md).

## Debian package

The x86_64 release includes a `.deb` package. See
[Debian and Ubuntu installation](./install.md#debian-and-ubuntu).

To build a Debian package locally, see
[Building the Debian package](./building-from-source.md#building-the-debian-package).
