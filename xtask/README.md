# `xtask`

Owns source installation, repository maintenance, code and documentation generation,
and development validation commands.

Run `cargo xtask install` to install Mitos and its runtime files. Use
`--root <path>` to install into `<path>/bin`, or `--profile <profile>` to choose
a build profile. See [building from source](../book/src/building-from-source.md)
for the full installation instructions.
